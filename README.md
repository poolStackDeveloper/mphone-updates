# MPhone 업데이트

본인 사용 업무폰용 MPhone의 서명된 APK와 업데이트 정보입니다.

**0.1.0은 초기 검증판입니다.** 앱 빌드·정적 검사와 관리 서버 로컬 테스트를 마쳤으나, NAS 관리 서버 배포와 실제 Galaxy S24 테스트는 완료하지 않았습니다. 관리 서버 주소와 전용 토큰 설정 없이 위치 확인·파일 업로드가 동작하지 않습니다.

- `phone-0.1.0.apk`: 업무폰용 앱
- `admin-0.1.0.apk`: 관리자용 앱
- `update.json`: 업데이트 버전·다운로드 주소·SHA-256

Android 14 이상에서 설치할 수 있습니다. 앱 설치·업데이트는 Android 설치 화면의 사용자 확인이 필요합니다. 공개 APK에는 NAS 비밀번호, 관리자 토큰, 단말 토큰 또는 서명 비밀키가 포함되어 있지 않습니다.

소스는 별도 비공개 저장소에서 관리합니다. 위치·사진·녹음 등의 실제 데이터는 이 저장소에 올리지 않습니다.
