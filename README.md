# N+스토리 업데이트

등록된 N+스토리 업무폰 앱과 N+스토리 관리자 앱의 공개 업데이트 저장소입니다.

- `phone-0.5.1.apk`: 업무폰 앱 업데이트
- `admin-0.5.1.apk`: 관리자 앱 업데이트
- `update.json`: 버전·다운로드 주소·SHA-256

**최초 설치에는 별도로 받은 개인용 등록 APK를 사용하세요.** 공개 APK에는 서버 비밀번호·사용자 토큰·일회용 등록 코드가 없으므로 공개 APK만 신규 설치하면 자동 등록되지 않습니다.

0.4.0은 N+스토리 이름·아이콘과 관리자 운영 설정(위치 간격·업로드 시간·종류별 사용 여부), 단말의 설정 수신·권한 상태 조회를 제공합니다. 두 앱을 함께 업데이트하세요. Google 지도 연결·사진 미리보기·녹음 재생도 유지됩니다. 단말에서 중지한 전송은 원격으로 재개하지 않습니다. 최초 수집 안내·Android 권한 요청·실행 알림·중지 기능을 유지합니다. Android 14 이상입니다. 0.5.0부터 약 6시간마다 다운로드·검증·자체 업데이트를 시도하며 Android가 요구할 때 설치 승인을 안내합니다. 각 앱의 앱 설치 허용을 처음 한 번 설정해야 합니다. 0.4.0 이하에서는 먼저 0.5.0을 한 번 설치하세요.

소스는 비공개 저장소에서 관리합니다. 실제 위치·사진·녹음은 이 저장소에 올리지 않습니다.

0.5.1: 업무폰 실행 상태 알림을 소리·진동·팝업 없는 낮은 중요도 채널로 표시합니다. 실행 상태와 중지 기능은 유지합니다.
